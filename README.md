# 🚀 CareerRadar AI
### Opportunity Intelligence Platform

**Discover. Track. Apply. Grow.**

CareerRadar AI is a job and internship discovery platform designed to help students and fresh graduates find relevant career opportunities in one place.

Instead of searching multiple websites, users can explore opportunities, discover jobs and internships, and keep track of their applications.

## ✨ Key Features

- 🔍 Discover job and internship opportunities.
- 💼 Explore opportunities from different sources.
- 🔄 Automatic opportunity updates.
- ⭐ Save interesting opportunities.
- 📋 Track application status.
- 📊 Manage your career opportunities in one place.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- SQLite
- Requests

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/priyanshimishra0501-hub/CareerRadar-AI.git
```

Open the project folder:

```bash
cd CareerRadar-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Project Goal

To make job and internship discovery easier for students by bringing career opportunities and application tracking together in one platform.
